# CMS für den PHZH-OER-Katalog

Browserbasiertes CMS (Vite + React, statisch, später auf GitHub Pages), mit dem
die Inhalte des OER-Katalogs über die GitHub-API bearbeitet werden. Die Oberfläche
ist deutsch und verwendet kein Git-Vokabular.

Konzept und Umsetzungsplan: siehe [`docs/`](docs/).

```bash
npm install
npm run dev     # localhost:5174
npm test
npm run build
```
